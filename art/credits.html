Artwork credits

Path of Exile, Path of Exile 2 and all included game artwork are copyright Grinding Gear Games. This is an unofficial, non-commercial fan project. No endorsement is implied.

Artwork is GGG game art, screenshots, official logos and wallpapers. PoE Wiki hosts copies of GGG assets; it is not credited as their creator.

Shared scenes illustrate the setting and are not represented as historical screenshots of the release. In particular, prototype/beta slots use later Act art; Harvest uses Act 2; Ultimatum and Allflame use Vaal art; Mirage uses the Wraeclast map. PoE 2 release scenes are selected wallpapers, not exact launch-screen reproductions.

The generated skill-web illustration has been removed. The player-count chart remains a data visualization.

Images are bundled locally as WebP; only resizing and compression are applied. The catalog records the original URLs, archive members, file hashes and slot mappings. Rebuild with python tools/import-art.py (requires Pillow).
